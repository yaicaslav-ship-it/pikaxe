Pickaxe Through Players (Fabric 1.21.4)

Локальная сборка: JDK 21 + Gradle 8.12 (или IntelliJ IDEA):
    gradle build
Jar: build/libs/pickaxe-through-players-1.0.0.jar

GitHub: загрузите проект в репозиторий. Вкладка Actions -> Build mod
соберёт jar автоматически; скачайте его из Artifacts.
Положите jar в папку mods вместе с Fabric API. Мод клиентский.
